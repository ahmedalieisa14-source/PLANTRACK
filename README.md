# ✨ PLANTRACK

PLANTRACK is a modern, aesthetic web app designed to help you organize tasks, set priorities, and stay motivated.  
It features a pastel interface, floating inspirational quotes, task saving with priority & due dates, and an AI-style tutor to help explain ideas and answer questions.

---

## 🚀 Features

- 📋 Add, delete & mark tasks as done  
- 📅 Set due dates + priority levels  
- 💾 Tasks saved in browser storage  
- ✨ Aesthetic UI with pastel gradients & floating shapes  
- 💬 Motivational quotes that change automatically  
- 🤖 Simple AI tutor interface for asking questions  
- 🌐 Two-page layout (Home & AI Tutor)

---

## 📁 Pages

- `index.html` → Main planner page  
- `tutor.html` → AI-style tutor chat interface

---

## 🛠 How to Use

1. Open `index.html` in your browser  
2. Add tasks with due dates + priority  
3. View completion progress  
4. Go to the AI Tutor page for explanations or help  

---

## 📦 Deployment (Host Online)
